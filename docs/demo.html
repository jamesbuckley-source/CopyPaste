CP CopyPaste · manual capture test

Every kind of thing you can copy

Copy any sample below, then open CopyPaste and check the badge, the sidebar slot and the quick actions. Colors, links, emails, Windows paths and JSON are all still text clips — what changes is how they are recognised and what the app offers to do next.

  1. 1 Press Copy on a sample
  2. 2 Open the overlay with Alt+V
  3. 3 Check badge, slot and actions
  4. 4 Try the search operator

Turn private mode off first, or the copies are deliberately skipped. Rich text needs Settings → Pasting → Paste with formatting; the low-confidence secret sample needs Settings → Capture → Guess from context. Synthetic credentials below are placeholders — never paste a real secret into a test page.

Colors

The entire copy must be one color value on one line. The app normalises it to #rrggbb for the swatch but keeps your exact text as the payload.

type:color
#6d8cffColor

The app's accent color. Try color:#6d8cff in search.

#FF6B6BColor

Uppercase is fine; the normalised value is #ff6b6b.

#8AFColor

Three-digit shorthand expands to #88aaff, the same as CSS.

#1f253380Color

Alpha is accepted, then dropped: the swatch is painted as #1f2533.

0xFF8800Color

The 0x prefix shows up in code; it normalises to #ff8800.

ff8800Color

No prefix needed. A bare value must contain both a digit and a letter.

c0ffeeColor

A word-shaped value still counts because it mixes 0 with letters.

rgb(255, 136, 0)Color

Comma-separated rgb().

rgba(255, 136, 0, 0.5)Color

Alpha is parsed, then ignored when painting the opaque sample.

rgb(255 136 0 / 50%)Color

CSS Color 4 spacing and alpha syntax.

rgb(100%, 53.3%, 0%)Color

Percentage channels are rounded to #ff8800.

Stays text

JSON

Valid JSON that starts with { or [ is tagged JSON and gains Format JSON in the preview pane. Formatting is view-only — the stored payload is never rewritten.

type:json
{ }
{"name":"CopyPaste","version":"0.8.1","features":["colors","links","paths","json"],"pinned":true}JSON

Minified object. Format JSON pretty-prints it in the pane.

[ ]
[{"id":1,"kind":"text"},{"id":2,"kind":"image"},{"id":3,"kind":"files"}]JSON

A top-level array is JSON too.

{ }
{ "name": "CopyPaste", "kind": "text", "contentKind": "json", "settings": { "pasteRichText": true, "detectSecrets": true }, "tags": ["demo", "json"] }JSON

Pretty-printed JSON is collapsed for the preview, then classified as JSON.

{ }
{"emoji":"📋","quote":"\"copy\"","url":"https://example.com","color":"#6d8cff"}JSON

Unicode and escaped quotes are valid; the whole payload is still JSON.

[ ]
[1, 2, 3, 4, 5]JSON

An array of numbers is JSON; a lone number is not.

Images

Bitmaps land in Images, not Text. Copy one from the page, then check the image preview, OCR text and drag-out support.

kind:image

If the browser blocks programmatic image copying, right-click the image and choose Copy image. Images can also be dragged out of CopyPaste as text/uri-list.

GIFs

Copying an animated GIF lands in Images like any other bitmap, but CopyPaste keeps the animation next to the still frame so the pasted result still moves.

kind:image

In the overlay the clip carries the animated GIF badge, and Add to GIFs on the clip puts it on the GIFs shelf. Browsers copy a GIF as a still frame, so this button publishes the image's HTML flavour as well — that is what CopyPaste follows back to the animation.

File lists

A file list is not something a web page can put on the clipboard. Make one in File Explorer: select files, press Ctrl+C, and CopyPaste records a Files clip with every path.

kind:files
  1. Run the PowerShell snippet below to create three small files in a demo folder.
  2. In File Explorer, select all three files and press Ctrl+C.
  3. Open CopyPaste: the preview should read 3 files · notes.txt, report.csv, readme.md.
  4. Copy a single file afterwards to see the 1 file shape.
Text
$demo = 'C:\Users\Public\Documents\CopyPaste-Demo'
New-Item -ItemType Directory -Force -Path $demo | Out-Null
Set-Content -Path "$demo\notes.txt" -Value 'Copied from the CopyPaste demo page.'
Set-Content -Path "$demo\report.csv" -Value "id,kind,contentKind`n1,text,color`n2,text,url`n3,files,"
Set-Content -Path "$demo\readme.md" -Value '# CopyPaste demo files'
Start-Process explorer.exe $demo

The script opens C:\Users\Public\Documents\CopyPaste-Demo. The generated paths also appear in the Paths section's spirit: copy one from Explorer to test Open and Open Folder.

Quick regression checklist

Other behaviours the samples are useful for.

  • Copy the same sentence twice: the existing clip is promoted, its copy count rises and it moves to the top.
  • Copy #ff8800 then rgb(255, 136, 0): both paint the same swatch but keep different payload text.
  • Pin a clip and check it appears under Pinned.
  • Tag a clip and search tag:demo.
  • Put a clip in a collection and search collection:Work.
  • Save a text clip, an image clip and a file list to a folder with Save as….
  • Drag a text, image and file clip out of the overlay.
  • Use Ctrl+1…9 to quick-copy the first nine clips.
  • Search type:url, type:email, type:path, type:json, type:color, type:markdown and type:secret to confirm each operator.
  • Expand the Text row in the sidebar and check that Link, Email, Path, JSON and Secrets filter correctly.
  • Select one clip and press Space: the quick preview opens with zoom for an image or an Edit button for text, and Space or Esc closes it. Edits save themselves. Zooming animates, the wheel zooms too, and a zoomed image is dragged rather than scrolled. A Markdown clip shows its formatting bar while editing.
  • Press Add clip in the toolbar, type a heading and a list with the Markdown buttons, and confirm the new clip carries the Markdown badge; a plain sentence gets the ordinary Text badge.
  • Tick a collection in the properties pane and confirm the pane does not blink as it saves.
  • Press the shield button in the properties pane on an ordinary text clip: it becomes a Secret with a blurred preview, and pressing it again makes it plain text.
  • Narrow the properties pane and confirm the Copy button keeps its icon and drops only the word, with every other action still visible.
  • Copy #6d8cff and confirm every place that shows the code uses #6D8CFF, while copying the clip still yields lowercase.
  • Set a folder in Settings → Markdown, then export a text clip with Ctrl+Shift+M and check the note's name, front matter and line endings. Deleting the folder first must produce an error, not a new empty folder.
  • Double-click a text clip in the list and confirm it is copied (and the window hides) rather than expanding.
  • Copy an image, open it, and confirm the Color scheme fills in by itself with up to five swatches — including an accent rather than five greys — and that clicking one copies its hex value.
  • Star a GIPHY result, then use Add GIF file in Utilities → GIFs to import a local .gif and copy it.
  • Toggle Loop above the GIF grid: on keeps every preview moving, off holds a still frame and plays only while you hover (history rows and cards behave the same way).
  • With Loop off, confirm imported GIF files and older favourites pause too, not just GIPHY results.
  • Click Make Color Palette after reading a scheme and confirm a new Color Palette 1 archive appears with every swatch.
  • Use New archive under Archives and confirm the collection is created already archived.
  • Open the setup wizard from Settings and confirm Next reaches Look & finish (step 3).
  • Change the sort dropdown between Last used and Captured orders and confirm the list reorders immediately.
  • Sample a screen color with the eyedropper and confirm the magnifier follows the crosshair without flicker.
  • Tick Window in the title bar, hover a window and confirm the cursor turns into a hand, then click it and check the clip has no stray strip down its left, right or bottom edge.
  • Click the full-screen capture button and confirm the clip is the whole desktop, with the app itself hidden from it.
  • Expand Images in the sidebar and open Screenshots: every capture above should be listed there and nothing copied from elsewhere.
  • Click the chevron at the sidebar's top-right to fold it into a rail, then click the rail to bring it back; drag one section heading onto another and confirm the order sticks after a restart.
  • Copy a photo of a person, wait a moment, then open Images → People: the photo should be listed and the preview pane should report how many faces were found.
  • Turn on Guess from context and re-copy the low-confidence secret sample.
  • Turn on Leave secrets out of history and confirm flagged samples are skipped.
  • Turn off Paste with formatting and confirm the rich sample pastes as plain text.
